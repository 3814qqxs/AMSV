# Project History

Decision ledger for the AMSV curation project (CLAUDE.md §2.4).

Keyed by ID, not by session or by file. **INDEX** is a fast-scan projection (ID / ASV Term / Rendering only) — check it first. **Translation Notes** is the full record — open it only when the index doesn't answer the question, or to check `Construction`/`Rationale`/`Reference` for a specific ID.

A root ID (`00042`) is a decision in its own right. A decimal ID (`00042.1`, `00042.2`, …) is a *different sense or construction* of the same ASV term that resolves differently — never conflate siblings, always check which one applies by source-language construction, not by the English phrase alone. Only settled decisions get a row; proposals live as `»` notes in the working book file until decided, then get a row here (§2.4). `Decision` states the tier and disposition (`tier1a`/`tier1b`/`tier2`, `applied`/`kept unchanged`/`declined`/`revised`). `Rationale` is compressed reasoning — cites external sources (lexicons, manuscripts, critical editions, outside research) when those were part of the basis, not only internal judgment. `Reference` is every verse the decision has been applied to that's been logged, abbreviated (Mt., Mk., Lk., Jn., Rom., 1 Cor., 2 Cor., Gal., Eph., Phil., Col., 1 Thess., 2 Thess., 1 Tim., 2 Tim., Titus, Phlm., Heb., Jas., 1 Pet., 2 Pet., 1 Jn., 2 Jn., 3 Jn., Rev.; Acts unabbreviated) — for Tier-1 mechanical rules applied wholesale across a book (Name Registry, R1.1, R9, R2), the source sessions mostly logged per-book counts or "applied" rather than individual verses, and that's what's reproduced here; exhaustive verse lists for those exist only where the original session recorded them.
